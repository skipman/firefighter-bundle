## Funktionsumfang

Moderne Plattform für Feuerwehren zur einfachen Verwaltung, Präsentation und Zusammenarbeit.

### Vorteile auf einen Blick

- Gemeinsame Nutzung und einfaches Teilen von Bild- und Videomaterial für Newsbeiträge  
- Deutlich geringerer Schulungsaufwand, da mehrere Feuerwehren dieselbe Plattform nutzen  
- Zahlreiche Darstellungsarten für Texte und Inhalte  
- Flexible und individuell gestaltbare Seitenlayouts  
- Eigene Stylings optional gegen Einmalzahlung möglich   
- Keine Einrichtungsgebühr  

### Funktionen im Detail

- Inhaltselemente zur übersichtlichen Darstellung von Einsatzmitteln, wie Feuerwehren, Fahrzeugen und Mannschaftsstärke  
- Automatische Verlinkung auf Detailseiten der ausgewählten Fahrzeuge  
- Zentrale Verwaltung von Mitgliederdaten inklusive lokaler und überörtlicher Funktionen  
- Einfache Zuweisung von Mitgliedern zu Gruppen, z. B. Kommando, Chargen, Aktivstand oder frei definierbaren Einheiten  
- Gefilterte Darstellung von Mitgliedergruppen für unterschiedliche Auflistungen  
- Organisationsübergreifende Nutzung von Mitgliederdaten, z. B. auf Abschnitts- oder Bezirksebene  

## Lizenzierung

Dieses Projekt ist Open Source und steht unter der GPL-3.0-or-later.

Für den produktiven Einsatz werden zusätzliche Services angeboten, darunter:

- Import aller für einen einfachen Start erforderlichen Basisdaten (Dienstränge, Funktionen, uvm.)
- Anlegen von Feuerwehren
- Lizenzverwaltung
- Erweiterte Funktionen
- Updates und Wartung
- Technischer Support
